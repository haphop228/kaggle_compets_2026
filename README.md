# Kaggle Competitions 2026 - Обзор решений

В данном репозитории представлены решения для трех соревнований. Ниже приведено описание опробованных моделей и подходов для каждого из них.

## 1) depression_posts_2026

**Опробованные модели и подходы:**
*   **Logistic Regression (Логистическая регрессия):** Использовалась как надежный бейзлайн. Было проведено множество экспериментов (версии `v2` - `v6`) с различными солверами (`lbfgs`, `saga`, `liblinear`), параметром регуляризации `C` и предобработкой (TfidfVectorizer, StandardScaler). Также проводился автоматический тюнинг гиперпараметров.
*   **LightGBM:** Градиентный бустинг над TF-IDF признаками.
*   **Complement Naive Bayes (CNB):** Наивный байесовский классификатор, хорошо подходящий для несбалансированных текстовых данных.
*   **SGD Classifier:** Линейный классификатор с функцией потерь `modified_huber`.
*   **LinearSVC:** Метод опорных векторов с калибровкой вероятностей (CalibratedClassifierCV).
*   **Ансамблирование (Ensembling):** Использовалось взвешенное усреднение предсказаний (блендинг). В последних версиях реализован перебор весов для тройных и четверных ансамблей (включающих логистическую регрессию, LightGBM и CNB) для максимизации OOF F1-score.

**Где искать лучшую модель:** 
Самый продвинутый ансамбль и итоговое решение находятся в файле [`depression_posts_2026/scripts/ensemble_v3.py`](depression_posts_2026/scripts/ensemble_v3.py).

## 2) house_prices_in_russia

**Опробованные модели и подходы:**
*   **LightGBM:** Основная модель, использовавшаяся на протяжении всех экспериментов. Обучалась как на исходном таргете, так и на логарифмированном (`y_log`). Проводился глубокий тюнинг гиперпараметров с помощью Optuna. Также тестировался тип бустинга DART.
*   **CatBoost:** Использовался в паре с LightGBM для создания разнообразия в ансамблях.
*   **XGBoost:** Добавлен в более поздних экспериментах для усиления ансамблей.
*   **Ансамблирование и Блендинг:**
    *   Простые взвешенные суммы (например, LGB + CB).
    *   Multi-model multi-seed ансамбли (обучение нескольких моделей с разными seed'ами для стабильности).
    *   Оптимизация весов блендинга с помощью Optuna и Grid Search.
    *   Сравнение блендинга в логарифмическом пространстве и в реальном пространстве.
*   **Стекинг (Stacking):** Использование Ridge и Lasso регрессии в качестве мета-моделей над OOF-предсказаниями базовых моделей.

**Где искать лучшую модель:**
Было много разных итераций, самая лучшая модель вот здесь:
[`house_prices_in_russia/scipts/train_v2.py)`](house_prices_in_russia/scipts/train_v2.py).

## 3) vacancies_2026_3_year

**Опробованные модели и подходы:**
*   **Ridge Regression (Гребневая регрессия):** Оказалась очень сильным компонентом. Обучалась на огромных разреженных матрицах TF-IDF (до 200k признаков). Проводился подбор параметра `alpha`.
*   **LightGBM & XGBoost:** Обучались на плотных признаках, полученных с помощью TruncatedSVD (снижение размерности TF-IDF), а также на дополнительных сгенерированных фичах. Экспериментировали с различными функциями потерь (RMSE, MAE, MAPE).
*   **CatBoost:** Тестировался с использованием встроенной обработки текстовых признаков (native text features).
*   **Feature Engineering (Генерация признаков):**
    *   Различные комбинации TF-IDF (слова + символы, раздельные TF-IDF для заголовков, описаний и навыков).
    *   KNN-признаки (поиск ближайших соседей).
    *   Продвинутая генерация признаков без использования внешних данных.
*   **Ансамблирование:** Поиск оптимальных весов для блендинга Ridge, LightGBM и XGBoost.

**Где искать лучшую модель:** 
Финальное решение с лучшим ансамблем (Ridge + LightGBM + XGBoost) и подобранными весами находится в ноутбуке [`vacancies_2026_3_year/train.py)`](vacancies_2026_3_year/train.py).
